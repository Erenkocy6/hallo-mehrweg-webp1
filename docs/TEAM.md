## Gemeinsam weiterarbeiten

1. Das öffentliche Repository ist angelegt; `origin` ist im lokalen Projekt bereits eingerichtet.
2. Alle Teammitglieder mit ihren eigenen Konten einladen.
3. Das Repository auf weiteren Rechnern klonen:

```sh
git clone https://github.com/Erenkocy6/hallo-mehrweg-webp1.git
```

4. Jede Person klont das Repository und nutzt ihre eigene Git-Identität. Änderungen in sinnvollen Arbeitsschritten selbst durchführen, prüfen und committen.
5. Vor Änderungen `git pull`, danach `git add DATEIEN`, `git commit -m "Konkrete Änderung"` und `git push`.
6. Bei paralleler Arbeit eigene Branches nutzen und Änderungen gegenseitig prüfen. Nicht gegenseitig ungeprüft die generierten HTML-Dateien überschreiben.
